# Wynn-Photon spell table (experimental, see docs/research/wynn-spells.md).
#
# Which textures are Wynncraft spell models, and which spell kind each one is. When the mod sees one of these textures
# on an item model, it hands the shader pack the kind's item ID instead of the item's own, and the pack gives the model
# the kind's glow and light. A kind is a look, not a spell: one glow rule and one light colour, which several spells
# can share. The kinds' glow rules and lights are in the pack, in include/misc/wynn_spells.glsl.
#
#   <item ID> sprite <texture name> <comment>   a texture by its name: Wynncraft's named ones (wynn/spell/...)
#   <item ID> pixels <hash> <comment>           a texture by a CRC-32 of its pixels, for Wynncraft's hashed texture
#                                               names (item/w<n>), which change every release. The spell debug log
#                                               prints each texture's hash
#   ? <item ID> ...                             a candidate: only used with the spell debug file
#                                               (config/wynn-photon-spell-debug), for a playtest to confirm
#
# Item IDs are 10128-10159; the kind is the ID minus 10128. The comment is the spell, for the debug log, and the texture
# name it had in the server pack the hash was taken from (Wynncraft's 2026-11-21 pack unless it says otherwise).
