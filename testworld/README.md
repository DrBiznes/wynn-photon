# Wynn-Photon test world

A creative superflat world with a gallery of every block Wynn-Photon changes, set up for looking at them under the dev
shader pack and the Wynncraft resource pack.

The easy way is `gradlew dev`, which starts a dev client with the shader mods already in this world (see "The dev
client" in the main README). To put the world in your own Minecraft instance instead:

```
gradlew installTestWorld
```

This task:

- runs `installDevPack`, then installs the world as `saves/Wynn-Photon Test` in the instance that holds `shaderpacksDir`
  (set in `local.properties`);
- copies the newest Wynncraft server pack that Minecraft cached in `downloads/` to the world's `resources.zip`. Minecraft
  asks to load it when the world opens. Join Wynncraft once with the instance first so the pack is cached;
- points Iris at `photon_v1.4 + WynnPhoton-dev`. Switch back in Iris's shader menu when you go back to playing.

Run it again after changing `work/` or the gallery. It replaces the datapack and the resource pack, but keeps the world.
`gradlew installTestWorld -Pfresh` deletes the world and starts over. The task refuses to touch a world folder it
didn't create.

## In game

- The gallery rebuilds every time the world loads. Run `/function wynn_photon_test:build` to rebuild it by hand, for
  example after breaking something.
- `/function wynn_photon_test:day` and `/function wynn_photon_test:night` set noon or midnight. Time and weather are
  frozen, and random ticks are off, so crops keep their age and vines don't spread.
- You spawn facing north at the **daylight row**: materials, specular, SSS and waving. Behind you is the **dark hall**:
  one light source per cell, behind a baffle wall, so the colors show without daylight.

## Editing the gallery

The `.mcfunction` files in `datapack/data/wynn_photon_test/function/` are generated by `gen_gallery.py` (except
`load`, `build`, `day` and `night`). Edit the script and run:

```
python gen_gallery.py datapack/data/wynn_photon_test/function
```

Wynncraft's custom blocks on `vine` states are fragile. A vine recomputes its faces when a neighbouring block changes,
and that turns the Wynn states into something else or into air. `vines.mcfunction` places them last, bottom to top,
and never side by side. Keep that true when adding exhibits.
